# DATN 1370 Datasets

Ten clean, ready-to-use datasets for student projects. Every file is a tidy CSV
(one row per observation, `snake_case` column names, no missing values, no
duplicate rows) and loads with a single `pd.read_csv(...)` call. Each one mixes
numeric, categorical, boolean and/or date columns so bar charts, histograms,
box plots, scatter plots, line charts and heatmaps all work out of the box
with seaborn and matplotlib.

The data is synthetic (generated by `generate_datasets.py` with a fixed random
seed), so it is safe to share and has been built with realistic relationships
to find: seasonal temperature cycles, study hours that raise scores, bigger
houses that cost more, and so on.

| # | File | Rows | Cols | Theme | Good for |
|---|------|-----:|-----:|-------|----------|
| 1 | `data/coffee_shop_sales.csv` | 6,000 | 13 | Transactions at 4 coffee shops over 2024 | bar charts, time series, group-by sums |
| 2 | `data/student_performance.csv` | 3,000 | 15 | High-school students, habits and test scores | scatter, regression, box plots by group |
| 3 | `data/city_weather_daily.csv` | 5,480 | 11 | Daily weather for 5 US cities, 2022-2024 | line charts, seasonality, histograms |
| 4 | `data/fitness_tracker.csv` | 6,000 | 13 | 100 users x 60 days of wearable data | per-user trends, box/violin plots |
| 5 | `data/housing_listings.csv` | 4,000 | 15 | Home listings across 8 cities | scatter, price-per-sqft comparisons |
| 6 | `data/movies.csv` | 3,000 | 13 | Films 1990-2024 with budget, box office, ratings | bar by genre, scatter, decade trends |
| 7 | `data/ecommerce_orders.csv` | 6,000 | 17 | Online store orders for 2024 | monthly trends, category mix, return rates |
| 8 | `data/employee_salaries.csv` | 3,500 | 13 | Employees across 8 departments | salary distributions, pay vs. experience |
| 9 | `data/music_tracks.csv` | 4,000 | 16 | Songs with audio features and popularity | correlation heatmaps, pair plots |
| 10 | `data/car_fuel_economy.csv` | 3,200 | 15 | Vehicles 2010-2024 with MPG and price | trends by year, comparisons by class |

## Quick start

```bash
pip install -r requirements.txt
python examples/quickstart.py      # makes one example chart per dataset in examples/charts/
```

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = pd.read_csv("data/coffee_shop_sales.csv", parse_dates=["date"])

sns.barplot(data=df, x="category", y="total", hue="store", estimator="sum", errorbar=None)
plt.title("Revenue by category and store")
plt.show()
```

Tips:

- Date columns are stored as `YYYY-MM-DD` text. Pass `parse_dates=[...]` to
  `read_csv` to get real datetimes you can group by month, weekday, etc.
- Boolean columns (`returned`, `has_garage`, `explicit`, ...) load as `True`/`False`.
- `examples/quickstart.py` has a copy-paste-ready chart for every dataset.
- To rebuild the CSVs run `python generate_datasets.py` (output is identical each time).

## Project ideas

- Which coffee store is busiest by hour, and does the mix of products change on weekends?
- Does sleep or screen time matter more for test scores once you control for study hours?
- How does the gap between daily high and low temperatures differ by city and season?
- Do advanced users sleep more, or just move more?
- Which city has the best value per square foot, and does a pool change the price?
- Which genre is the safest bet for a studio: highest median profit or lowest chance of a loss?
- What is the return rate by category, and does it rise during the holiday rush?
- How much of the salary gap between departments is explained by job level and experience?
- Which audio features travel together, and has danceability changed by decade?
- How fast have gasoline cars improved compared with hybrids since 2010?
